# Security Policy

## Supported Versions

SiliconPulse provides security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of SiliconPulse very seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report it privately:

1. **Email**: Send an email describing the vulnerability with steps to reproduce to [rajesh.c.git@gmail.com](mailto:rajesh.c.git@gmail.com).
2. **GitHub Security Advisory**: Use the [GitHub Private Vulnerability Reporting](https://github.com/rajeshc-git/silicon-pulse/security/advisories/new) tool.

### What to Include
- Detailed description of the vulnerability.
- Steps or proof-of-concept (PoC) to reproduce the issue.
- Your macOS version and Apple Silicon model (e.g. M1, M2, M3, M4).
- Impact assessment.

### Response Timeline
- **Initial Response**: Within 48 hours.
- **Status Updates**: Regular updates regarding fix progress.
- **Public Disclosure**: Coordinated disclosure after a fix has been released.
